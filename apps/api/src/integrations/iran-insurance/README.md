# اتصال آینده به API بیمه ایران

این پوشه فقط ساختار (contract) آماده برای اتصال آینده را نگه می‌دارد؛ **هیچ اتصال واقعی
پیاده‌سازی نشده است**، دقیقاً طبق دستور پروژه.

وقتی مستندات رسمی API بیمه ایران در اختیار قرار گرفت:

1. پیاده‌سازی واقعی متدهای `IranInsuranceClient` در `client.ts` تکمیل شود.
2. متغیرهای محیطی لازم (`IRAN_INSURANCE_API_KEY`, `IRAN_INSURANCE_BASE_URL`) به `.env` اضافه شوند.
3. مسیرهای API جدید (مثلاً استعلام حق بیمه آنلاین) در `apps/api/src/routes` اضافه شوند.

تا آن زمان، تمام فرآیندها (ثبت درخواست مشاوره، صدور و غیره) دستی و از طریق پنل مدیریت
انجام می‌شود؛ طبق بریف پروژه هیچ صدور آنلاینی در این نسخه وجود ندارد.
