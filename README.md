به مدیریت ملیحه علوی.

## ساختار مونوریپو (Turborepo + pnpm)

```
hemayatgar-insurance/
├── apps/
│   ├── web/     # Next.js 15 + React 19 + TypeScript + Tailwind — سایت عمومی + پنل مدیریت
│   └── api/      # Express.js + TypeScript — تمام سرویس‌های بک‌اند
├── packages/
│   ├── database/ # Prisma schema + PostgreSQL client مشترک
│   ├── config/    # تنظیمات مشترک
│   └── ui/        # کامپوننت‌های React مشترک
├── scripts/
│   └── backup-db.sh
├── docker-compose.yml
├── DEPLOYMENT.md
└── ...
```

## شروع سریع (توسعه محلی)

```bash
pnpm install
cp .env.example .env   # مقادیر را تنظیم کنید

pnpm --filter @hemayatgar/database prisma:generate
pnpm --filter @hemayatgar/database prisma:migrate
pnpm --filter @hemayatgar/database prisma:seed   # کاربر مدیر کل + داده اولیه می‌سازد

pnpm dev   # اجرای هم‌زمان web (پورت ۳۰۰۰) و api (پورت ۴۰۰۰)
```

بعد از seed، با ایمیل و رمز عبور تعریف‌شده در `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD`
(پیش‌فرض: `admin@hemayatgar.ir` / `ChangeMe123!`) از مسیر `/admin/login` وارد پنل شوید و
**بلافاصله رمز عبور را تغییر دهید**.

برای استقرار روی سرور، به `DEPLOYMENT.md` مراجعه کنید.

## نکات مهم طبق بریف پروژه

- این پروژه ERP، CRM بزرگ، سیستم مالی، سیستم انبار یا سیستم صدور آنلاین **نیست**.
- هیچ درگاه پرداخت یا صدور آنلاینی پیاده‌سازی نشده است.
- اتصال به API بیمه ایران عمداً پیاده‌سازی نشده؛ فقط ساختار آماده آن در
  `apps/api/src/integrations/iran-insurance/` قرار دارد (به README همان پوشه مراجعه کنید).
- زیررشته‌های بیمه به‌صورت پیش‌فرض سکشن مستقل داخل صفحه رشته اصلی هستند، نه صفحه جدا.
